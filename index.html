MDS — Manual Reversion
Switching displays manually in the event of an undetected Display Unit (DU) failure
Purpose
⚠ Manual reversion is used when an undetected DU failure occurs — the system does not auto-reconfigure.
Use the display selector switches on each flight crew's brightness control panel
Located in front of the control column on each side
Switch has three positions: NORM, OUTBOARD, INBOARD
Power-Up Behaviour
During power-up, each DU reads its position pins
The position latches into DU memory
If a DU cannot read position pins → DU is blank
Display Selector Switch Positions
N
NORM
Normal displays show on both inboard and outboard DUs
O
OUTBOARD
Inboard DU goes blank. Outboard DU: outboard half = cropped PFD, inboard half = engine display (or last shown format)
I
INBOARD
Outboard DU goes blank. Inboard DU shows: cropped PFD + engine display (or last shown format)

MDS — Displays-Source Switch
Selecting which Display Processor Computer (DPC) controls the display units
What the Switch Does
The DISPLAYS-SOURCE switch selects which Display Processor Computer (DPC) controls the display units
Normally in the AUTO position
Switch Positions
A
AUTO (normal)
No failures: DPC 1 → Left DUs (LOB + LIB); DPC 2 → Right DUs (RIB + ROB). With a failure, routing adjusts automatically to keep all display data available.
1
ALL ON 1
DPC 1 controls all four display units. PFD shows DSPLY SOURCE 2 — indicating DPC 2 is not supplying display data.
2
ALL ON 2
DPC 2 controls all four display units. PFD shows DSPLY SOURCE 1 — indicating DPC 1 is not supplying display data.
⚠ Training Point: The PFD message tells you which DPC is NOT supplying data — the opposite of the switch position selected.
